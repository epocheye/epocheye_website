# Narration voices: licences

Checked on **2026-11-16** from the primary sources linked below (model cards, repository
licence files, dataset pages). Question asked of each: may audio made with this model and this
voice be published on a public commercial website?

This is a record of what the sources say. It is not legal advice.

## Voices that may be shipped

### Kokoro-82M: `kokoro-heart` (voice pack af_heart)

| Item | Licence | Source |
|---|---|---|
| Model weights and voice packs, `hexgrad/Kokoro-82M` | Apache-2.0 | https://huggingface.co/hexgrad/Kokoro-82M (card metadata `license: apache-2.0`) |
| Inference library `kokoro` 0.9.4 | Apache-2.0 | https://github.com/hexgrad/kokoro/blob/main/LICENSE |
| Text front end `misaki` | Apache-2.0 | https://github.com/hexgrad/misaki/blob/main/LICENSE |
| Fallback for words outside the dictionary, `espeak-ng` | GPL-3.0 | https://github.com/espeak-ng/espeak-ng/blob/master/COPYING (local tool, not shipped) |

- The card says: "With Apache-licensed weights, Kokoro can be deployed anywhere from production
  environments to personal projects." No usage restriction is stated.
- Voices: the voice packs are files in the same Apache-2.0 repository. `VOICES.md`
  (https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md) gives a quality grade for each
  voice and no separate licence or speaker provenance for the English voices.
- Training data, as the card describes it: public domain audio, audio under Apache or MIT,
  two CC BY datasets (Koniwa `tnc`, SIWIS), and synthetic audio generated by closed TTS models.
  The card states no restriction arising from any of these.
- The other English voice packs in the repository (for example bf_emma, bm_george) are under
  the same licence. They were not rendered or measured here.
- Accent: American (`a`) and British (`b`) English only. Kokoro has no Indian English voice.
  Its Hindi voices are made for Hindi text. The narration does not use them. The open world's
  role figures do, for English lines (see the next section).

| `hm_psi` | The mason (`w-mas-*`), English text | Hindi, male, target quality B, overall grade C | Apache-2.0, as a file in the model repository |

## Rejected

### Chatterbox (`ResembleAI/chatterbox`), built-in default voice: REJECTED, not installed, not run

- Code and weights are MIT (https://github.com/resemble-ai/chatterbox/blob/master/LICENSE,
  Copyright (c) 2025 Resemble AI; card metadata `license: mit`).
- The problem is the voice, not the licence of the model. Chatterbox is a zero-shot cloning
  model: every output is conditioned on a reference speaker. With no `audio_prompt_path` it
  loads a stored speaker conditioning, `conds.pt`, described in the code as the built-in voice
  (`src/chatterbox/tts.py`: `if (builtin_voice := ckpt_dir / "conds.pt").exists(): conds = Conditionals.load(...)`;
  `generate()` refuses to run with no conditioning). That object has the same form as the one
  `prepare_conditionals()` computes from a reference clip.
- The only statement about where the prompts come from is the README disclaimer:
  "Prompts are sourced from freely available data on the internet."
  (https://github.com/resemble-ai/chatterbox/blob/master/README.md).
- So the default voice rests on a recording of an unidentified person, with no licence,
  consent or identity published. That fails two rules of the brief at once: no cloning of a
  real person's voice, and no voice whose licence is unclear.
- Also noted: every Chatterbox output carries Resemble AI's Perth neural watermark.

### Piper `en_GB-vctk-medium` (109 VCTK speakers): REJECTED, not downloaded

- It was considered because the VCTK corpus is CC BY 4.0
  (https://datashare.ed.ac.uk/handle/10283/3443, `license_text.txt`: "Creative Commons License:
  Attribution 4.0 International") and, from memory and not checked today, includes a few
  speakers with Indian accents.
- Its model card says "Finetuned from U.S. English lessac voice (medium quality)"
  (https://huggingface.co/rhasspy/piper-voices/blob/main/en/en_GB/vctk/medium/MODEL_CARD).
- The lessac dataset licence allows research only and excludes "using the Materials for any
  commercial purpose"
  (https://www.cstr.ed.ac.uk/projects/blizzard/2013/lessac_blizzard2013/license.html).
- A voice fine-tuned from a research-only model is unclear for commercial use. Rejected.
- The same applies to every other Piper voice whose card says it was fine-tuned from lessac.
  Seen today: `en_GB-alan-medium`, `en_GB-aru-medium`, `en_US-libritts_r-medium`. And to
  `en_US-lessac-*` itself.

## Credits line

"Narration: synthetic voice." (PLAY_BRIEF 5.8). If a Kokoro voice ships, Apache-2.0 asks for
the licence notice to travel with redistributed copies of the *model*; the audio is not the
model, so no notice is required in the game, but naming the model in the site credits costs
nothing.

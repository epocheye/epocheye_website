### Meta tags

- **Canonical tags:** none on any page of either site.
- **Meta descriptions:** present on most routes. `/login` and `/admin` fall back to the root description.
- **Open Graph and Twitter:**
  - Title, description and type only. **There is no og:image, og:url or og:site_name.**
  - The root og:title ("Bringing the Experience to Heritage Tourism") appears on every page and differs from each page's `<title>`.
- **`metadataBase`:** falls back to `http://localhost:3000` when the env var is missing (`app/layout.js:10-18`). `.env.local` sets neither `NEXT_PUBLIC_SITE_URL` nor `NEXT_PUBLIC_APP_URL`, so the Vercel env settings need checking. The fix is to hard-code the canonical host.
- **Backend CORS:** still uses `https://epocheye.app` as the origin (`backend/serverless.yml:20,24`, `backend/src/app.ts:18`). Align it with the canonical host.
- **Structured data:** **none** anywhere.
- **Noindex:** none on admin, login, dashboard or share pages.

The apex and www serve duplicate content with no canonical, so ranking signals are split. **Decision (owner, 2026-09-30):** the canonical host is `https://www.epocheye.com`. Apex, `epocheye.app` and `www.epocheye.app` should 308 to it.

## 5. GEO: llms.txt

**Not built.** The evidence says no major engine consumes it:

- Google: Gary Illyes said in July 2025 that Google does not support llms.txt and does not plan to. John Mueller said "no AI system currently uses llms.txt" and compared it to the keywords meta tag. ([Search Engine Land](https://searchengineland.com/google-says-normal-seo-works-for-ranking-in-ai-overviews-and-llms-txt-wont-be-used-459422), [Search Engine Journal](https://www.searchenginejournal.com/google-says-llms-txt-is-purely-speculative-for-now/577576/))
- OpenAI, Anthropic and Perplexity document crawler access through user agents and robots.txt, not llms.txt. A log study of about 515 million AI-bot requests found the share of requests for `/llms.txt` statistically negligible. ([llmpulse](https://llmpulse.ai/blog/llms-txt-guide/))
- There is one caveat: SEJ reports that Google's guidance "depends on which product you ask" ([SEJ](https://www.searchenginejournal.com/googles-llms-txt-guidance-depends-on-which-product-you-ask/575431/)). Nothing there shows the file is consumed for citation.

Revisit if any engine documents consumption.
